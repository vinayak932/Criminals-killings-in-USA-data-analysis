# Criminals Killings in USA Data Analysis

An Exploratory Data Analysis (EDA) project on **fatal police shootings in the United States**, using the **Washington Post Fatal Police Shootings** dataset along with socioeconomic and demographic data to uncover trends, patterns, and relationships.

## Project Overview

This project explores thousands of police fatality records and combines them with city and state-level demographic indicators such as poverty rates, education levels, and racial composition.

The goal is to answer questions like:

* Which states report the highest average poverty rates?
* Which cities record the highest number of police killings?
* How does age vary by gender and manner of death?
* What weapons were people armed with most frequently?
* How do race distributions differ across major cities?

## Dataset

The analysis uses publicly available datasets including:

* Washington Post Fatal Police Shootings Dataset
* City and state demographic data
* Poverty rate statistics
* Education (high school completion) data
* Racial composition data

The project includes analyses such as:

### Socioeconomic Analysis

* Average poverty rate across states
* High school completion vs poverty rate
* Relationship between education and poverty

### Geographic Analysis

* Top 10 cities with the highest police killings
* State-wise comparisons
* Race distribution within major cities

### Weapon Analysis

* Most common weapons involved
* Grouping smaller weapon categories into **Others**
* Interactive Plotly visualizations

## Key Insights

Some notable findings from the analysis include:

* Significant variation in poverty levels across U.S. states.
* Certain cities account for a disproportionately high number of police killings.
* Firearms are the most frequently reported weapon category.
* Age distributions differ across gender and manner of death.
* Racial representation among police killings varies between major cities.
